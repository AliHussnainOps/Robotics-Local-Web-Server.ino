
# Robotics Local Web Server

## Project Overview
This project uses an ESP32 microcontroller
to create a local web server for robotics
system monitoring and control.

## Hardware Components
- ESP32 Development Board
- Red LED
- Green LED

## Features
- Local Wi-Fi connectivity
- HTTP Web Server on Port 80
- Robotics Control Dashboard
- Operational Mode
- Safety Halt Mode

## GPIO Connections
- Red LED: GPIO 25
- Green LED: GPIO 26

## Technologies
- C++
- Arduino IDE
- HTML
- CSS
- JavaScript
- ESP32 Wi-Fi

## How to Use
1. Configure your Wi-Fi credentials.
2. Upload the code to ESP32.
3. Open Serial Monitor at 115200 baud.
4. Copy the ESP32 IP address.
5. Open the IP address in a browser.
6. Use the dashboard to control LED status.
